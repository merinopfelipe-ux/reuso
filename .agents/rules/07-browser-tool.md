# Regla de uso del navegador

- **NUNCA** abrir el navegador (`browser_subagent`) de forma autónoma o directa.
- Revisa las solicitudes inspeccionando el código fuente, componentes y lógica en el repositorio.
- Si consideras que es necesario o conveniente usar el navegador (por ejemplo, para una verificación visual compleja), **pídele o recomiéndale al usuario el permiso** en la conversación.
- Abre el navegador **únicamente** cuando el usuario te lo confirme o lo solicite explícitamente.
