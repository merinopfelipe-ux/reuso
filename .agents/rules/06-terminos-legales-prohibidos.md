# Pilar 6: Términos Legales Prohibidos y Comunicación

Este pilar define las reglas estrictas de lenguaje para cumplir con las políticas legales y de exención de responsabilidad de Reúso (Grupo MLP S.A.S.).

## A. Palabras Prohibidas (MANDATORIO Y PERMANENTE)
Bajo ninguna circunstancia se pueden utilizar las siguientes palabras, sus sinónimos o derivados en la interfaz de usuario, landing page, SEO, meta descripciones o reportes generados por la plataforma.

- **Certificar / Certificación / Certificado / Certificable**
  - **Motivo:** Reúso es un software de cálculo, gestión y trazabilidad, NO una entidad certificadora externa ni gubernamental. No emitimos certificaciones oficiales.
  - **Alternativas permitidas:** Documentar, reportar, respaldar, estructurar, validar, reportes, memorias de sostenibilidad, validaciones corporativas, sustentar.

- **Rigor científico / Científicamente comprobado**
  - **Motivo:** Utilizamos bases de datos internacionales (IPCC, Ecoinvent) procesadas mediante Inteligencia Artificial. No realizamos análisis científicos de laboratorio para cada usuario.
  - **Alternativas permitidas:** Bases técnicas, fundamentos técnicos, bases de datos internacionales reconocidas, cálculos estructurados, referencias técnicas.

- **Exacto / Preciso / Exactitud / Precisión absoluta / Absoluto**
  - **Motivo:** Los cálculos de emisiones (CO2) y agua son estimaciones basadas en promedios y factores de conversión sectoriales. Pueden existir márgenes de error e imprecisiones propias de la IA.
  - **Alternativas permitidas:** Estimado, proyectado, calculado, detallado, sustentado, aproximado, trazabilidad técnica.

- **Garantizar / Infalible / 100% seguro / Promesas absolutas**
  - **Motivo:** Ningún software es infalible ni podemos prometer resultados comerciales definitivos (ej. "Te garantizamos vender más").
  - **Alternativas permitidas:** Facilitar, asistir, potenciar, promover, proveer herramientas para, habilitar.

- **Instantáneo / Inmediato / En segundos (en procesamiento de IA)**
  - **Motivo:** Los tiempos de respuesta dependen del rendimiento del navegador y de la red. Prometer instantaneidad puede considerarse publicidad engañosa en términos de servicio.
  - **Alternativas permitidas:** Automatizado, ágil, en tiempo real, optimizado, rápido.

- **Sin alucinaciones / Cero alucinaciones / Algoritmo infalible**
  - **Motivo:** Los modelos de IA generativa y visión por computadora conllevan intrínsecamente un margen de imprecisión o sesgo de reconocimiento.
  - **Alternativas permitidas:** Algoritmos técnicos, motor asistido por IA, enfoque estructurado, lógica determinista asistida.

- **Inmutable / Inviolable**
  - **Motivo:** La inmutabilidad estricta solo aplica a redes blockchain descentralizadas o hashes criptográficos auditados; no debe usarse como promesa comercial ligera.
  - **Alternativas permitidas:** Registro digital, trazabilidad técnica, pasaporte digital, registro con sellos de seguridad.

## B. Voz Activa (MANDATORIO)
Toda comunicación escrita, copy y texto en la plataforma debe redactarse en **voz activa**, con un tono directo, profesional y claro.
- *Incorrecto:* "Las estimaciones de CO2 serán calculadas por el sistema usando las bases de datos."
- *Correcto:* "El sistema estima tu huella de carbono usando bases de datos internacionales."
- *Incorrecto:* "El pasaporte digital es generado para asegurar la trazabilidad."
- *Correcto:* "Reúso genera el pasaporte digital para asegurar tu trazabilidad."
